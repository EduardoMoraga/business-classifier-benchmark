# Visual direction

Audience: hiring managers, analytics leaders, and business stakeholders.

Visual concept: a model room, not a generic SaaS dashboard. The page should feel like an analyst opening the hood of a classifier.

Palette:
- Ink: #101820
- Ledger green: #244c3a
- Signal amber: #d99b2b
- Paper: #f7f3e8
- Error red: #9f3328
- Steel: #6f7d86

Typography:
- System-first for reliability.
- Large compact numerals for metrics.
- Avoid decorative chart junk.

Hero:
- A side-by-side "decision bench" showing the same employee row scored by classical ML, Jev, and Laya.
